📖 User Guide

Calculator Hub combines four calculators in one. Switch tabs, use keyboard shortcuts, and enjoy mobile-friendly touch controls.

⌨️ Keyboard Shortcuts

Works when no input field is focused. Use Tab to move focus away.

KeyAction
0-9 .Enter numbers / decimal
+ - * /Operators (add, subtract, multiply, divide)
%Percentage (Standard / Scientific)
^Exponentiation (Scientific only)
Enter or =Calculate result
BackspaceDelete last character
EscapeClear (AC)

🧮 Standard Calculator

Basic arithmetic: addition, subtraction, multiplication, division, and percentages.

  • % — percentage of first value (e.g. 200 + 10% = 220)
  • AC — clears everything
  • DEL — removes last digit

🔬 Scientific Calculator

Trigonometry, logarithms, exponentiation, constants, and parentheses.

sin / cos / tanTrigonometric (degrees)sin(30) = 0.5

💻 Programmer Calculator

Bitwise operations and base conversion (Binary, Octal, Decimal, Hex).

  • Base dropdown — switch between BIN, OCT, DEC, HEX
  • AND / OR / XOR / NOT — bitwise logic
  • << / >> — bit shift left / right
  • Conversions — DEC, BIN, HEX shown in real time

Example: In Decimal, 5 AND 3 = 1. In Hex, A + 5 = F.

📅 Age Calculator

  • Enter your date of birth
  • Check "Use today as target date" for current age
  • Or uncheck to pick a custom target date
  • Press Calculate Age to see years, months, and days
